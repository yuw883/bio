1.1

生物學是甚麼

生物學是研究生物和生命現象的科學,內容包括生物的結構、功能、生長、遺傳、分類、生態與演化。

  • 屬於生物學範疇:研究細胞結構、植物如何進行光合作用、疾病的成因、生物之間及生物與環境的關係。
  • 不屬於生物學範疇:岩石的形成(地球科學)、金屬的性質(化學)、光的折射(物理)。
判斷方法:先看研究對象。研究的對象是生物或生命活動,就是生物學;只研究非生物的物質或現象,就屬於其他科學。
1.2

生物的特徵

生物有七項基本特徵。判斷一個對象是否為生物,要看它是否同時表現這些特徵。

特徵意思例子
感應對環境刺激作出反應含羞草被觸碰後葉片合攏;植物的根向水生長
運動身體或身體一部分改變位置動物走動;植物的葉片向光轉動
營養獲取並利用物質作為能量和生長的來源植物光合作用;動物進食
呼吸分解有機物,釋放能量細胞進行有氧呼吸
排泄排出新陳代謝產生的廢物呼出二氧化碳;排出尿液
生長體積和質量不可逆地增加幼苗長成大樹
生殖產生後代,延續物種細菌分裂;動物產卵、產仔
易錯:排泄是排出代謝廢物,排出未消化的食物殘渣(排遺)不算排泄。生長要求是不可逆的增大,食物吃飽後體重增加不是生長。

從情境判斷生命特徵

  • 火焰會「燃燒、變大」,也需要氧氣,但它沒有細胞、不能感應、不能生殖,所以不是生物。
  • 汽車會移動、消耗燃料並排出廢氣,但不能生長和生殖,所以不是生物。
  • 答題格式:先說出特徵名稱,再引用情境中的證據。例如「植物的根向水生長,這是感應」。

單細胞生物能否獨立完成生命活動

可以。單細胞生物(例如變形蟲、草履蟲、細菌)只有一個細胞,但這個細胞自己完成感應、運動、營養、呼吸、排泄、生長和生殖等全部生命活動。多細胞生物則由不同的細胞分工合作。

延伸:病毒是特別情況。病毒沒有細胞結構,只有核酸和蛋白質外殼。單獨存在時只是顆粒,沒有生命特徵;寄生在宿主細胞內才能複製,表現出生物特徵。所以病毒通常被視為非生物的特別情況。
1.3

研習生物學的重要性

  • 健康與醫學:了解身體運作,預防和治療疾病,例如疫苗和藥物的研發。
  • 食物與農業:改良作物和家畜,增加糧食生產。
  • 環境與生態:了解生物與環境的關係,保護生物多樣性,應對污染和氣候變化。
  • 科技發展:基因工程、生物科技等都建基於生物學知識。
  • 個人決策:對飲食、運動、健康資訊作出有根據的判斷。

作答時要配合題目情境,舉出具體例子,不要只寫「對人類有幫助」。

1.4

科學方法

觀察→提出問題→提出假設→設計及進行實驗→分析數據→得出結論

可測試的假設

  • 假設是對問題的暫時解釋,必須能用實驗或觀察檢驗。
  • 常用句式:「如果改變(自變量),那麼(因變量)會……」。
  • 例:如果增加光照強度,那麼植物的光合作用速率會增加。

三種變量

變量意思例子(光照強度對植物生長的影響)
自變量實驗者刻意改變的因素光照強度
因變量隨自變量改變而被量度的結果植物高度
控制變量必須保持不變的其他因素植物品種、水量、溫度、泥土種類
易錯:控制變量不是「不用理會的因素」,而是要刻意保持相同,否則無法確定結果由自變量引起。每次只改變一個自變量。
1.5

進行科學探究

分析數據及得出結論

  • 先描述趨勢(上升、下降、先升後降),再引用具體數值支持。
  • 結論要回應假設:數據支持還是不支持假設。結論只能由數據推出,不能超出數據的範圍。

樣本量與可靠性

  • 樣本量越大、重複實驗次數越多,結果越可靠,偶然誤差的影響越小。
  • 只用一株植物做實驗,結果可能只是個別差異。

實驗結果的限制

  • 樣本太少、控制變量未做好、量度工具不夠精確。
  • 結果只適用於實驗所用的條件和對象,不能隨便推廣到所有情況。

科學知識會改變

科學知識建基於證據,出現新證據時,舊的解釋可能被修正。科技進步令觀察更精細,例如顯微鏡讓人發現細胞,電子顯微鏡讓人看見細胞內更細小的結構。

2.3

細胞的基本結構

細胞學說及相關科學家

科學家貢獻
胡克(Hooke)首次用顯微鏡觀察軟木薄片,命名為「細胞」
施萊登(Schleiden)提出植物由細胞組成
施旺(Schwann)提出動物由細胞組成
魏爾肖(Virchow)提出「細胞來自細胞」
易錯:植物是施萊登,動物是施旺,兩人不要對調。胡克看到的是軟木的死細胞壁。

細胞結構與功能的關係

答題邏輯:細胞的功能需要甚麼 → 由哪個細胞器負責 → 所以含有大量該細胞器。

白血球溶酶體要分解入侵的細菌以保護身體,溶酶體含水解酶

2.4

身體的組織層次

細胞→組織→器官→系統→生物體
  • 組織:形態和功能相似的細胞組成。人體有四大類:上皮組織、結締組織、肌肉組織、神經組織。
  • 器官:由不同組織組成,執行特定功能。
  • 系統:由多個器官合作,完成一類生命活動,例如消化系統。

按複雜程度排序:細胞器 < 細胞 < 組織 < 器官 < 系統 < 生物體。

以胃為例:胃是器官,屬於消化系統。內壁的上皮組織分泌胃液,肌肉組織令胃蠕動,神經組織傳遞信號,結締組織連接和支持其他組織。作答時要寫出器官由哪幾種組織組成,以及各組織的功能。

原核、植物及動物細胞的共同結構

三者都有細胞膜、細胞質、核糖體,並以 DNA 作為遺傳物質。

繪畫及標注

原核細胞要標注

細胞壁、細胞膜、細胞質、擬核(DNA)、核糖體;有些細菌還有鞭毛。

動物細胞要標注

細胞膜、細胞質、細胞核、線粒體、內質網、高爾基體、核糖體等。

植物細胞要標注

在動物細胞的基礎上加上細胞壁、葉綠體、大液泡,並去掉中心體。

畫圖要點:用鉛筆和直尺畫標注線,標注線不可交叉,線尾要指向結構本身。圖要寫上標題,結構要按比例畫,細胞核不要畫得太小。
自測

快速檢查

1. 細菌是單細胞生物,它能獨立完成所有生命活動嗎?

可以。單細胞生物的一個細胞就能完成感應、運動、營養、呼吸、排泄、生長和生殖。

2. 實驗中「保持不變」的因素叫甚麼?

控制變量。

3. 誰提出動物由細胞組成?

施旺(Schwann)。植物則是施萊登(Schleiden)。

4. 為甚麼胰腺細胞含有大量 rER 和高爾基體?

胰腺細胞要分泌大量消化酶(蛋白質)。rER 合成蛋白質,高爾基體加工和分泌蛋白質,所以含有大量這兩種細胞器。

5. 哪些細胞器具有雙層膜?

細胞核(核膜)、線粒體、葉綠體。

6. 由小到大排列:器官、細胞、系統、組織。

細胞 → 組織 → 器官 → 系統。

7. 原核細胞與真核細胞最主要的分別是甚麼?

原核細胞沒有核膜包圍的細胞核,也沒有膜細胞器;真核細胞有。
